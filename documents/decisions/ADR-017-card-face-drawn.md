# ADR-017: 卡面用绘制，不抓官网照片

**Status:** Superseded by ADR-018 (2026-11-06) —— 第 1 条「不抓官网照片」已被推翻，第 2 条（品牌色独立文件）仍然有效
**Related:** ADR-014（卡库数据同步）

## Background

用户要求「直接搜那张卡的样子出来，网上找资料，把卡面搜出来」，同时希望界面好看些。

卡库列表当时是纯文字：卡名 + 银行名 + 一个百分比。8 张卡要逐行读卡名才找得到目标。加卡面缩略图是合理诉求。

## Decision

### 1. 卡面用 SVG/CSS 绘制，不抓银行官网图

实测了 23 个发卡行官网，结论：

| 类别 | 结果 |
|---|---|
| 澳门 17 张卡的官网 | JS 空壳、Incapsula 反爬、只有 PDF 条款。**抓不到图** |
| 香港大行 | 能抓到，但各家图片规则互不相同 |
| 汇丰 | 有干净的 1600×900（卡面居中、纯色底），裁切后效果很好 |
| DBS / 恒生 | 684×630 方图、1920×280 banner，带场景和人物，要逐张裁且要判断卡的位置 |
| 中银香港 | 只有活动 banner，没有卡面图 |

放弃抓图的三条理由，按权重排序：

1. **配错卡比没有卡面糟得多。** 38 张卡要逐张打开图确认「这是不是那张卡」。一旦某张配错，用户会以为自己手里拿的是另一张，而这是决策工具，认错卡等于给出错误建议。
2. **覆盖率不可控。** 澳门 17 张抓不到，香港 21 张能抓一部分。结果是「有的有图有的没图」，列表里出现两种视觉密度，比统一没有更难看。
3. **营销图的版权属于银行。** 个人自用风险低，但把别人的营销素材打包进自己分发的前端，不是可以默认的事。

绘制方案：品牌色底 + 银行缩写 + 卡组织标识，38 张全覆盖、零请求、零版权风险。在 48px 高度上，辨识靠的本来就是「颜色块 + 形状」，不是卡面细节。

真卡面照片后续可以放进**详情页**（单张大图，空间够），但列表不用。详情页要的是「这是我的卡」的确认感，那里放一张 480×303 的真图是成立的。

### 2. 品牌色进 `design/card-brand.css`，不进 `design-tokens.json`

`design-tokens` 是**界面语义色**：surface / fg / accent / pos / neg。它们随主题走、承担语义、由设计系统决定。

卡面品牌色是**外部品牌标识**：汇丰的红是汇丰的，不是「危险」的；不随主题变化，也不该由设计系统挑选。并在一起会让后来的人以为可以改，而那等于改别人的 logo。

同时它也不适合自动生成：源数据是各行公开的标识色，不是设计师的决策，加一行就是加一个色，没有派生逻辑。

`-ink`（压在品牌色上的文字色）按 WCAG 相对亮度预先算好写死。Mox 的亮青底（相对亮度 0.466）上放白字只有 2.1:1，必须用黑。写在文件里而不是运行时算，是为了让「这批色各自配什么字」在一处可见、可审。

### 3. 取不到官方色的银行用中性灰，不猜

澳门本地行（BCM / 澳门国际 / 立桥）拿不到可信的官方色，落到 `--brand-neutral: #3a4048`。

最初用了深蓝 `#2c3a52`，结果和 BNU 的 `#1e335a` 并排像同一张卡的两个副本。改成中性灰后区分开。

不猜色的原因：猜错的代价不是难看，是让用户凭颜色认错卡。

### 4. 同银行多卡叠明度台阶

汇丰 4 张卡共用 `#db0011`，并排是 4 块一模一样的红。按卡在发卡行内的序号叠 3 档黑（26% / 36% / 54%），做出「同系不同款」的层次。

只往暗走，不做提亮：试过第 3 档叠白 15%，深红变粉色，读起来像印刷褪色。一路加深反而符合真实的卡等级系列（普卡→金卡→白金→黑卡）。

封顶 3 档：第 4 档之后暗到看不出是张卡。

### 5. 行高 64 → 72

72 = 卡面 48 + 上下内边距 12×2。做过 64，那个高度下卡面只能到 40，卡组织标识糊成色块，「一眼认出是哪张卡」这个前提就不成立了。

改的是 `design/design-tokens.json` 的 `size.listRow`，不是 CSS —— CSS 是 `gen-tokens` 的生成物。

## Consequences

**正面**

- 38 张卡全部有卡面，零网络请求，不增加 PWA 体积（纯 CSS/SVG，约 2KB）
- 品牌色集中在一个文件里，可审、可改，不散落在组件
- 同一家银行的卡有多档层次，列表不再是一片同色

**负面**

- 不是真卡面。预期用户第一眼会问「这不是我那张卡的样子」
- 品牌色表要维护。新增银行若不填，会落到中性灰
- 明度台阶是人为的层次，与真实的卡等级无关，不构成任何产品信息

## 返工记录

初版把百分比放行尾独立列（76px 卡面 + 72px 百分比 + 16px 箭头），卡名只剩 174px，「BCM World Mastercard」被截成「BCM World Master...」——认不出是哪张卡，卡面带来的辨识度全赔进去了。

改为：卡名独占一行（可用宽度 282px），百分比下移到副行右端，去掉行尾箭头（整行本就可点）。

教训：**给列表加图形元素时，必须先量文字还剩多少宽度**。图形是从文字手里抢空间，不是凭空加。

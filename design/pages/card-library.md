# 页面：卡库管理页 `/cards`（含模板选择器）

> 路由：`/cards`（TabBar 第 2 项）
> 关联：F2（卡库自助增删改 + 模板一键带出）/ F6（数据新鲜度）
> 基准视口：375 × 812
> 继承：`MASTER.md`。本文只写该页特有的 px 级布局

---

## 1. 这一屏承担什么

用户每月来看 1–2 次，目的是「加一张新卡」或「改一个费率」。**不追求好看，追求扫得快、改得准。**

关键约束：卡库有 12 张预置 + 用户自加，最多约 30 张（SPEC §10）。一屏必须能扫到 6–7 张（`VISUAL_DENSITY=6`）。

## 2. 整体布局

```
┌───────────────────────────────────────────────────┐
│ [顶栏] 48px + --safe-top                          │
│  我的卡（8）                        [plus] 44×44   │
├───────────────────────────────────────────────────┤
│  共 8 张 · 2 个地区 · 2 张本月额度已用尽             │ 12px --meta, pad 12
├───────────────────────────────────────────────────┤
│  澳门发卡                              11px --meta │ 分组标题
│  ─────────────────────────────────────────────    │
│  [卡行 64px] × N                                  │ divide-y
│  ─────────────────────────────────────────────    │
│  香港发卡                                          │
│  ─────────────────────────────────────────────    │
│  [卡行 64px] × N                                  │
│                                                   │
│                              ┌──────────┐         │
│                              │    +     │ FAB     │
│                              └──────────┘ 56×56   │
├───────────────────────────────────────────────────┤
│ [算一笔]        [我的卡 ●]        [设置]            │ TabBar 56px
```

| 容器 | 规格 |
|---|---|
| 根 | `flex column; height: 100dvh` |
| 列表 | `flex: 1; overflow-y: auto`；`padding-bottom: calc(var(--size-tabbar) + var(--safe-bottom) + 80px)`（80px 给 FAB 让路） |
| 分组 | **不用卡片包裹**（`VISUAL_DENSITY=6`）。分组之间用 `--space-6`（24px）留白 + 11px 分组标题 |

## 3. 顶栏（48px）

| 元素 | 规格 |
|---|---|
| 标题 | `我的卡（8）` —— 18px / 590 / `--fg`。**括号内是总数，实时更新** |
| 右侧 | `plus` 24px `--muted`，容器 44×44，`aria-label="添加卡片"`。**与 FAB 功能重复是有意的**：列表滚到底时顶栏已滚走，FAB 在右下；在顶部时 plus 更顺手 |
| 背景 | `--surface-0`，无底边框 |

## 4. 统计条

```
y: 64 ─────────────────────────────────────
  共 8 张 · 2 个地区 · 2 张本月额度已用尽
  12px / 400 / --meta        padding: 12px 16px
```

- **它是扫读摘要，不是仪表盘。** 不给它卡片、不给它大数字、不加图标。
- 数量变化即文本变化（`共 9 张`），不做数字滚动动画。
- 没有卡时不显示这条（让空状态独占视野）。

## 5. 卡行（CardListItem，64px）

```
x:16 ─────────────────────────────────────────── x:359
┌──────────────────────────────────────────────────┐
│ 汇丰 PULSE 银联双币钻石信用卡          2.00%  ›   │  y:0  h:22
│ 16px/510 --fg                        15px tabular │
│ 银联 · 双币 · 额度 MOP 5,000                      │  y:22 h:18
│ 12px --meta                                      │
│ 本月已用 MOP 3,040 · 26%  ▁▁▁▁░░░░░              │  y:40 h:16
│ 12px --meta               4px 条 64px 宽          │
└──────────────────────────────────────────────────┘  分隔线 --line-subtle
```

| 元素 | 规格 |
|---|---|
| 行高 | **64px**（`--size-row-list`） |
| 左右 padding | 16px |
| 分隔 | `divide-y` → `border-bottom: 1px solid var(--line-subtle)`；**最后一行也保留**（与分组留白形成节奏） |
| 第一行左 | 卡名 16px / 510 / `--fg`，`clamp 1 行` |
| 第一行右 | **本卡最高费率** 15px / 510 / `--fg-2`，`tabular-nums`，右对齐，固定宽 56px；后接 `chevron-right` 16px `--muted` |
| 第二行 | 12px / 400 / `--meta`：`{卡组织} · {单/双币} · 额度 {币种} {金额}` |
| 第三行（仅有上限时） | 左：`本月已用 MOP 3,040 · 26%`（12px `--meta`，`tabular-nums`）；右：**微进度条** 64×4px |
| 无上限的卡 | 第三行写 `无月度上限`（12px `--meta`），**不画条** |

**微进度条 vs 完整进度条（重要区分）**
- 列表里的条是 **64px 宽的「微条」**，只给一眼判断，不带刻度、不带数字标签以外的信息
- 额度页的条是**完整条**（6px 高，满宽）
- 两处都用同一套三色规则（`--pos` / `--warn` / `--neg`）

**状态**

| 态 | 规格 |
|---|---|
| default | 如上 |
| hover（仅 `@media (hover:hover)`） | 整行底 `--surface-2` |
| active | 底 `--surface-2`（触屏按下反馈） |
| focus-visible | 整行 3px `--accent-text` 环，offset −2px（内嵌，避免被相邻行裁切） |
| disabled（停用卡） | 整行 `opacity: 0.5`；第二行末尾加 tag `已停用`（11px `--muted`，底 `--line`）。**不删除**——保留账本历史（ARCHITECTURE §3.6 `Card.active`） |
| 数据过期 >90 天 | 第二行末尾加 11px `--warn` 文字 `124 天未核对`（**不用徽章**，一行文字更轻） |
| 左滑删除 | 滑出 88px `--neg` 底 + `trash-2` 20px + `删除` 13px，白字（`--on-accent`）。松手后弹二次确认 |

**边界**

| 情况 | 处理 |
|---|---|
| 卡名超长（用户自输入） | `clamp 1` + 省略号。**不允许两行**——两行会让 64px 行高崩掉 |
| 费率为 unknown | 右侧显示 `未知`（13px `--muted`），**不显示 `0%`** |
| 额度为 0 或未填 | 第三行写 `额度未填`，不画条 |
| 停用 + 过期 + 已用满 | 最多同时出现 3 个附加信息。**按优先级只显示最高那个**：停用 > 已用满 > 过期 > 正常。理由：一行里堆 3 个警示等于没有警示 |

## 6. 分组

| 分组 | 条件 | 顺序 |
|---|---|---|
| `澳门发卡` | `issuerRegion === 'MO'` | 1 |
| `香港发卡` | `issuerRegion === 'HK'` | 2 |
| （已停用） | `active === false` | 3，最后一组，组标题 `已停用 · 1 张` |

**美国分组已移除**（SPEC §0：`IssuerRegion` 收窄为 `'MO' | 'HK'`）。

分组标题规格：11px / 510 / `--meta`，`letter-spacing: var(--tracking-caps)`（0.06em），`padding: 0 16px`，上距 24px。

> **不用 `01 / 02` 编号。** 那是 AI 脚手架的语法。分组标题只能是事实性（`澳门发卡`）或状态性（`已停用 · 1 张`）。

## 7. FAB

| 项 | 规格 |
|---|---|
| 尺寸 | 56 × 56，`--radius-pill` |
| 位置 | `position: fixed; right: 16px; bottom: calc(var(--size-tabbar) + var(--safe-bottom) + 16px)` |
| 视觉 | 底 `--accent`，`plus` 24px `--on-accent`，`--elev-raised` |
| hover | 底 `--accent-hover` |
| active | 底 `--accent-active` + `transform: scale(0.96)`（**唯一允许缩放的按钮**，因为它是浮动元素，缩放不引起布局位移） |
| focus-visible | 3px `--accent-text` 环，offset 3px |
| 键盘弹出 | `bottom` 改为 `calc(var(--keyboard-inset, 0px) + 16px)` |
| 触屏 | 有 `aria-label="添加卡片"`（纯图标按钮必须有） |

## 8. 添加卡片 sheet

点 FAB 或顶栏 plus → bottom sheet（`--surface-3`，顶角 12px，`max-height: 88vh`）。

```
┌──────────────────────────────────────────────────┐
│              ▁▁▁▁  handle                         │
│  添加卡片                                  [x]    │
├──────────────────────────────────────────────────┤
│                                                   │
│  ┌─────────────────────────────────────────────┐ │
│  │ [layers 20]  从模板添加                      │ │  ← 主推，56px，底 surface-4
│  │ 12 张港澳常见卡，规则自动带出，只改额度      │ │     13px --fg-2
│  └─────────────────────────────────────────────┘ │
│                                                   │
│  ┌─────────────────────────────────────────────┐ │
│  │ [pencil-line 20]  手动添加                   │ │  ← 次级，ghost，48px
│  │ 空白表单，自己填规则                         │ │
│  └─────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────┘
```

| 项 | 规格 |
|---|---|
| 「从模板添加」 | 底 `--surface-4`，1px `--line-strong`，`--radius-lg`，高 56px，图标 20px `--accent-text`，主标题 16px/510 `--fg`，副标题 13px `--fg-2` |
| 「手动添加」 | 透明底，1px `--line`，`--radius-lg`，高 48px，图标 20px `--muted`，文字 15px `--fg-2` |
| 层级理由 | 模板添加是**主路径**（12 张预置卡覆盖 90% 场景），手动是**逃生舱**。视觉必须明确分出主次，不能让两个选项等权 |

## 9. 模板选择器（TemplatePicker）

从「从模板添加」进入，同一 sheet 内替换内容。

```
┌──────────────────────────────────────────────────┐
│  ← 添加卡片                                [x]    │
├──────────────────────────────────────────────────┤
│  ┌─────────────────────────────────────────────┐ │
│  │ [search 16] 搜索银行或卡名                   │ │  高 44px
│  └─────────────────────────────────────────────┘ │
│  澳门 · 常见                                       │  11px --meta 0.06em
│   大丰银联双币钻石卡（大湾区卡）    最高 5%  ▸     │  64px
│   中银全币种信用卡                  费率待补  ▸    │
│  香港 · 常见                                       │
│   汇丰 PULSE 银联双币钻石信用卡    费率待补  ▸    │
│   渣打 Simply Cash Visa 卡          最高 2%  ▸    │
│   大丰...                                         │
└──────────────────────────────────────────────────┘
```

| 项 | 规格 |
|---|---|
| 搜索框 | 高 44px，底 `--surface-2`，1px `--line`，`--radius-md`，左 `search` 16px `--muted`，placeholder `搜索银行或卡名`（14px `--disabled`） |
| 搜索匹配 | 对 `issuer` + `cardName` 做 `includes` 匹配（含繁体/英文，不转小写以外不做模糊） |
| 分组 | 按 `issuerRegion`：`澳门 · 常见` / `香港 · 常见`（**无美国**） |
| 模板行 | 高 64px，卡名 15px / 510 / `--fg`（clamp 1）+ 右侧**费率摘要** 13px / `--muted` + `chevron-right` |
| 费率摘要规则 | 取 `categories` 里最高的一档：`最高 5%`。**全部 `unknown` 时写 `费率待补`**（13px `--muted`）——绝不能写 `0%`（那会让用户以为是一张废卡） |
| 选中 | 行底 `--accent-tint` + 1px `--accent`（100ms 后自动进入编辑页） |
| 空搜索结果 | `没找到这张卡`（16px/510 `--fg`）+ `预置模板只有港澳常见卡。这张可以手动添加，规则自己填。`（13px `--fg-2`）+ 主按钮 `手动添加` |
| 列表滚动 | `max-height: 60vh; overflow-y: auto` |

**筛选数据的来源**：12 张预置精选（SPEC §3.2），**不是 38 张全量**。19 张卡返现侧字段空白，全量上线会让用户看到大量「净返还 0/负」，而那是「我们不知道」而非「卡不好」，会误判产品价值（ARCHITECTURE R9）。

**选中后的体验（关键）**：直接进编辑页，**所有字段已预填**，顶部一条提示条：

```
┌──────────────────────────────────────────────────┐
│ [info 16] 已从模板带出规则，请确认额度上限          │ 13px --info, 底 --info-tint
└──────────────────────────────────────────────────┘
```

用户只改一件事（额度），不是填十件事。这是「一键带出」的全部价值。

## 10. 空状态 / 错误状态

| 场景 | 表现 |
|---|---|
| 卡库为空 | 居中（`padding: 64px 32px`）：`layers` 24px `--muted` → `卡库里还没有卡`（18px/590 `--fg`）→ `从预置的 12 张港澳常见卡里选一张，规则会自动带出来，你只要确认额度。`（14px `--fg-2`，`max-width: 280px`）→ 主按钮 `从模板添加`（44px，`--accent`） |
| 读不到数据 | 顶部 banner（`--neg-tint` 底，`triangle-alert` 16px `--neg`，`读不到卡片数据`，右侧 ghost `重试`）+ 列表区显示 3 行骨架（**仅此时用骨架**，因为确实在尝试读） |
| 单张卡数据过期 | 行内 11px `--warn` 文字 `124 天未核对`，点击进详情可一键确认（AC-F6-02） |

---

## 11. 响应式

| 断点 | 变化 |
|---|---|
| <375px | gutter 12px；费率列 48px |
| ≥640px | `max-width: 640px; margin: 0 auto`；FAB 位置改为相对内容列右缘 |
| ≥1024px | 同 640 单列。**不做双列网格**——64px 行 × 单列是扫读最快的形态，双列会让「本月已用」这类信息被切成两半 |

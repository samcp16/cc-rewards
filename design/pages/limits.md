# 页面：额度页 `/limits`

> 路由：`/limits`（**并入「我的卡」内部 tab**，不是 TabBar 独立项，SPEC §7）
> 关联：F5（上限与门槛建模）
> 基准视口：375 × 812
> 继承：`MASTER.md`。本文只写该页特有的 px 级布局

---

## 1. 这一屏承担什么

回答一个具体问题：**「每张卡的额度还剩多少，我还能不能刷它？」**

用户在两种时刻打开它：
1. 在收银台前，答案卡说「额度已用完」，他来看还剩哪张能用
2. 月初/月末，看哪些额度已重置

**这不是数据看板。** 不给图表、不给趋势线、不给环形图、不给大 KPI 卡。只给「还剩多少」和「够不够这一笔」。

---

## 2. 位置：作为「我的卡」的内部 tab

SPEC §7 明确：「额度并入『我的卡』内部 tab」。TabBar 仍是 3 项（算一笔 / 我的卡 / 设置）。

```
┌───────────────────────────────────────────────────┐
│ [顶栏] 我的卡（8）                        [plus]   │
├───────────────────────────────────────────────────┤
│  ┌──────────────┬──────────────┐                  │
│  │   卡片 8      │   额度 5      │  ← 内部 tab       │
│  └──────────────┴──────────────┘    高 44px        │
├───────────────────────────────────────────────────┤
│  [本页内容：额度列表]                              │
├───────────────────────────────────────────────────┤
│ [算一笔]        [我的卡 ●]        [设置]            │
└───────────────────────────────────────────────────┘
```

**内部 tab 规格**

| 项 | 值 |
|---|---|
| 容器 | 底 `--surface-0`，下边框 1px `--line-subtle`，`padding: 0 16px` |
| 按钮 | `flex: 1`，高 44px，文字 15px / 510 |
| 未选中 | 文字 `--muted`，无指示条 |
| 选中 | 文字 `--fg` + **底部 2px `--accent` 指示条**（贴容器下边框） |
| 徽章 | 额度 tab 数字后带计数 `5`，13px `--muted`。**不用红点、不用角标**——红点暗示"有待办"，而额度用尽是常态不是待办 |

> **为什么不用独立的第 4 个 TabBar 项**：SPEC §7 锁定 3 项。而且 TabBar 每多一项，主任务「算一笔」的拇指路程就变远一分。额度是低频检查，不是高频任务。

## 3. 页面结构

```
┌───────────────────────────────────────────────────┐
│  本月 MOP 已用 HK$4,120 / 上限合计 HK$1,340        │  ← 汇总条（1 行）
│  5 张卡有月度上限 · 2 张已用尽                      │  12px --meta
├───────────────────────────────────────────────────┤
│   已用尽                                        │  ← 分组（有则显示）
│  ───────────────────────────────────────────────  │
│  [卡 96px]                                        │
│  ───────────────────────────────────────────────  │
│  用到 80% 以上                                     │
│  ───────────────────────────────────────────────  │
│  [卡 96px]                                        │
│  ───────────────────────────────────────────────  │
│  额度充足                                          │
│  ───────────────────────────────────────────────  │
│  [卡 96px] × 3                                    │
└───────────────────────────────────────────────────┘
```

**分组逻辑**：按「用户下一步该做什么」排序，不按卡名或金额。

| 分组 | 条件 | 为什么这个顺序 |
|---|---|---|
| `已用尽` | `used / limit >= 1` | 唯一需要用户改变行为的组 → 置顶 |
| `用到 80% 以上` | `0.8 <= ratio < 1` | 需要留意 → 第二 |
| `额度充足` | `ratio < 0.8` | 不需要关注 → 最后 |

**没有卡设上限时**：不显示任何分组，整页显示空状态（见 §6）。

## 4. 汇总条

```
y: 108 ────────────────────────────────────────────
  5 张卡有月度上限 · 2 张已用尽
  13px / 400 / --meta        padding: 12px 16px
```

| 项 | 规格 |
|---|---|
| 内容 | `{n} 张卡有月度上限 · {m} 张已用尽`（`m = 0` 时省略后半句） |
| 字号 | 13px / 400 / `--meta` |
| **不做「总计已用 / 总计上限」的大数字横幅** | 各卡的币种与周期不同（HKD / MOP；月 / 半年 / 年），加总无意义。加总出来的数字会误导用户以为「我还有 X 元额度」——这是典型的「看似有用的假仪表」。**只在同币种同周期时提供加总，且必须标注口径**：

```
  本月 · 港元卡合计
  已用 HK$1,340 / 上限 HK$2,060     65%
```

同币种同周期的加总才有意义。混币种时只给卡数。

## 5. 卡额度行（96px，完整进度条）

```
x:16 ─────────────────────────────────────────── x:359
┌──────────────────────────────────────────────────┐
│ 中银香港 Chill 信用卡                [查看]  ›    │  y:12  h:22
│ 16px/510 --fg                          13px --info│
│ 额外回赠 · 每月                                   │  y:34  h:18
│ 13px --meta                                      │
│ ▁▁▁▁▁▁▁▁▁▁▁▁▁▁░░░░░░░░░░░░░░░░░░░░░░              │  y:56  h:6
│ 已用 HK$96 / HK$150 · 64%      剩 HK$54           │  y:68  h:18
│ 13px --meta tabular                               │
└──────────────────────────────────────────────────┘
```

| 元素 | 规格 |
|---|---|
| 行高 | **96px**，`padding: 12px 16px` |
| 分隔 | `border-bottom: 1px solid var(--line-subtle)`；行本身**无卡片框、无圆角** |
| 卡名 | 16px / 510 / `--fg`，`clamp 1` |
| 右上 | `查看` 13px `--info` + `chevron-right` 16px `--muted`（整行可点，进卡详情） |
| 副标题 | 13px / 400 / `--meta`：`{上限名称} · {周期}`（如 `额外回赠 · 每月`） |
| **进度条** | 满宽（343px），**6px** 高（`--bar-normal`），`--radius-pill`，轨道 `--line-strong`，填充 `transform: scaleX()` |
| 数字行 | 左：`已用 HK$96 / HK$150 · 64%`（13px `--meta`，`tabular-nums`）；右：`剩 HK$54`（13px / 510 / 语义色） |

**三色规则（与 MASTER §3.4 一致）**

| ratio | 填充色 | 数字区附加 |
|---|---|---|
| `< 0.8` | `--pos` | `剩 HK$54` 用 `--fg-2`（**不染绿**——充足不是好消息，是常态） |
| `0.8 – 0.99` | `--warn` | 数字前加 `triangle-alert` 14px `--warn` + `剩 HK$24` 用 `--warn` |
| `>= 1` | `--neg` | `triangle-alert` 14px `--neg` + `已用完` 文字 + `剩 HK$0` |

> **`< 0.8` 时不要给「剩 HK$54」染绿。** 绿色在本产品只有「省钱」一个含义（SPEC §8）。额度充足不是省钱，如果染绿，用户会以为「额度多 = 我赚了」。这会让绿色失去唯一的语义。

**边界**

| 情况 | 处理 |
|---|---|
| 已用 > 上限（如 112%） | 条按 100% 封顶绘制；数字显示真实值 `已用 HK$168 / HK$150 · 112%`，并加 `--neg` 文字 `超额` |
| 上限为 0 或未填 | 条不渲染，数字行显示 `额度未填`（13px `--muted`） |
| 周期为年/半年 | 副标题写 `额外回赠 · 每年` / `· 每半年`，数字行前加口径 `今年` / `本半年` |
| 同一张卡多个上限池 | **每池一行 96px**，卡名只在第一池显示，后续池卡名位置留空（缩进对齐），副标题区分池名 |
| 停用卡 | 整行 opacity 0.5 + 末尾 tag `已停用`；仍显示额度（用户可能想重新启用） |
| 无任何上限的卡 | **不出现本页**。这一页只列有上限的卡 |

**多池的排布示意**

```
中银香港 Chill 信用卡                          ›
额外回赠 · 每月
▁▁▁▁▁▁▁▁░░░░░░░░░░  已用 HK$96 / HK$150 · 64%   剩 HK$54
Chill 商户加码 · 每月
▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁░░░  已用 HK$220 / HK$260 · 85%   剩 HK$40
```

## 6. 空状态与错误

| 场景 | 表现 |
|---|---|
| **没有任何卡设上限** | `padding: 64px 32px` 居中：`circle-slash` 24px `--muted` → `没有卡设了月度上限`（18px/590 `--fg`）→ `有上限的卡会在这里显示已用和剩余。`（14px `--fg-2`，`max-width: 280px`）→ 无 CTA（这不是用户需要行动的空态） |
| **账本为空（本月还没记账）** | 所有条显示 `已用 HK$0 · 0%`，但**顶部加一行**（13px `--info`，`--info-tint` 底）：`这个月还没记过账。用过之后点「记一笔」，这里就会准。` + 右侧 `记一笔` 链接 |

> 账本为空时**不能什么都不说**。否则用户看到全部 0%，会以为「额度很充足」，实际是「我们不知道用了多少」——这是最危险的一种误导（比 unknown 更隐蔽，因为 0% 看起来是个确定的数）。

| 场景 | 表现 |
|---|---|
| 读不到数据 | 顶部 banner `--neg-tint`：`读不到卡片数据` + `重试` |
| 某卡上限周期冲突（如 EarnMORE 按年） | 该行数字行末尾加 13px `--warn`：`上限口径待核对` + 进详情可看具体冲突说明 |

## 7. 与答案卡的关系（跨页一致性）

主查询页答案卡底部那条 4px 微条与这里的 6px 完整条**必须用同一套三色与同一套数字格式**。

| 项 | 答案卡微条 | 本页完整条 |
|---|---|---|
| 高度 | 4px | 6px |
| 宽度 | 96px | 满宽 343px |
| 颜色规则 | 同一套（`--pos` / `--warn` / `--neg`） | 同一套 |
| 数字 | `已用 26%` + `剩 MOP 1,960` | `已用 HK$96 / HK$150 · 64%` + `剩 HK$54` |
| 数据源 | `Scheme.capsAffected` | `CapDefinition` + 账本 |

**为什么不完全一致（微条只给百分比、完整条给绝对额）**：答案卡空间只有 96px，塞进 `HK$96 / HK$150` 会溢出；本页有全宽，必须给绝对额，因为用户的直觉单位是「多少钱」而不是「百分之几」。

---

## 8. 响应式

| 断点 | 变化 |
|---|---|
| <375px | 数字行右侧 `剩 HK$54` 可能换行 → 字号降到 12px；条高保持 6px |
| ≥640px | `max-width: 640px; margin: 0 auto` |
| ≥1024px | 同 640 单列。**不做多列网格**——额度条需要横向量度，双列会让条变短 40%，比较能力丧失 |

# 页面：主查询页 `/`

> 路由：`/`（默认首页，打开即用，**无欢迎页**，SPEC §7）
> 关联：F3（快速测算）/ F1（净回报比较）/ F4（算式展开）
> 基准视口：**375 × 812**（iPhone 13 mini–14 之间）
> 继承：`MASTER.md` 全部内容。本文只写该页特有的 px 级布局

---

## 1. 这一屏承担什么

用户 66% 的使用时间在这屏。他站在收银台前，手上有 5 秒。

**这一屏唯一要完成的事：让他改一个数字，然后在拇指上方看到一个会跟着变的答案。**

没有「查询」按钮，没有结果页路由，没有跳转（SPEC AC-F3-02 / UIUX §2.3）。改任一输入 → 200ms 内答案更新。

## 2. 整体布局（flex column，三段式）

```
┌───────────────────────────────────────────────────┐
│ [顶栏] 48px + --safe-top                           │  fixed
├───────────────────────────────────────────────────┤
│                                                   │
│ [输入区] 可滚动                           ← 分区 1–4
│   padding: 16px 16px 0
│                                                   │
├───────────────────────────────────────────────────┤
│ [答案卡] sticky bottom                            │  z-index 100
│   高 180–200px（按内容 3 态不同）                    │
├───────────────────────────────────────────────────┤
│ [TabBar] 56px + --safe-bottom                     │  z-index 110
└───────────────────────────────────────────────────┘
```

**技术细节**

| 容器 | 规格 |
|---|---|
| 根 | `display: flex; flex-direction: column; height: 100dvh`（用 `dvh` 不用 `vh`：iOS 地址栏收起时 `vh` 会导致答案卡被顶出视口） |
| 顶栏 | `height: calc(var(--size-topbar) + var(--safe-top)); padding-top: var(--safe-top); flex-shrink: 0` |
| 输入区 | `flex: 1; overflow-y: auto; -webkit-overflow-scrolling: touch`；`padding-bottom: calc(答案卡高 + var(--content-pad-bottom) + var(--space-4))` |
| 答案卡 | `position: sticky; bottom: var(--content-pad-bottom)`。**必须 sticky 而非 fixed**：fixed 会脱离文档流，输入区底部的内容永远滚不出来 |
| TabBar | `position: fixed; bottom: 0`，`height: calc(var(--size-tabbar) + var(--safe-bottom))` |

>  **答案卡的高度会影响输入区的 padding-bottom，而答案卡高度随状态变化（空态 / 有结果 / 失格）。** 三个状态的高度必须**在视觉噪声可接受的前提下尽量接近**：空态用 `min-height` 撑到与有结果态相同（约 196px），只有失格态允许缩到 160px。理由是高度跳变会让内容区滚动位置抖动，用户在输入时页面会「自己动」。

### 4.3 分区 3 · 金额

```

      │  HK$  [        380.00            ]  │

      └─────────────────────────────────────┘
       x:16                          x:359
```

| 项 | 值 |
|---|---|
| 标签 | `这笔消费多少`，12px `--muted`，下距 8px |
| 容器 | 高 **56px**，底 `--surface-2`，1px `--line`，`--radius-md`，`padding: 0 var(--space-4)`，`display: flex; align-items: center; gap: var(--space-2)` |
| 币种前缀 | `HK$`，16px / 400，`--muted`，**不可编辑**（币种随地区：澳门 → `MOP`，内地 → `CN¥`） |
| 输入 | `flex: 1`，`text-align: right`，28px / 590，`--fg`，`tabular-nums`，`background: transparent`，`border: none` |
| 占位 | `0.00`，`--disabled` 色 |
| 键盘 | `inputmode="decimal"`，`type="text"`，`autocomplete="off"` |
| **不 autofocus** | iOS 禁止无手势聚焦，`autoFocus` 会被忽略。用户点一下即聚焦（SPEC AC-F3-04） |
| 聚焦 | 容器边框 → `--accent-text`；`outline: 3px var(--accent-text); outline-offset: 2px` |
| 错误 | 容器边框 `--neg`；下方 `--space-2` 处 13px `--neg` 行 + `triangle-alert` 16px：`金额得大于 0` |

**边界（必须实现，前端最容易漏）**

| 情况 | 处理 |
|---|---|
| 金额 > 99,999 | 字号 28px → **20px**（降一级），保留千分位。**绝不截断、绝不横向滚动** |
| 粘贴 `1,234.56` | `onPaste` 清洗所有非 `[0-9.]` 字符 |
| 输入多个小数点 | 只保留第一个 |
| 输入 0 / 负数 / 空 | **不计算**，回到空态引导。0 与负数额外显示错误行 |
| 失焦 | 格式化为 2 位小数（输入过程中不格式化，避免打字被打断） |
| 8 位小数 | 输入允许，失焦截断到 2 位（展示层）；计算层用全精度 |

## 5. 答案卡（sticky 底部，180–200px）

### 5.1 结构（有结果态，总高 196px）

```
y: 0 ─────────────────────────────────────────────
│ padding: 16px 16px 0                             │
│                                                  │
│ 刷这张                              12px --meta   │  y:16
│ 汇丰 PULSE 银联双币钻石信用卡         24px/590 --fg │  y:34  h:30  clamp 2
│ [credit-card 16] 刷卡 · 澳门币结算   13px --fg-2   │  y:68  h:18
│                                                  │
│ +MOP 23.40                          40px/590 --pos│  y:96  h:44
│ 净返 2.34%  ·  比第二名多 MOP 12.80   13px --meta   │  y:142 h:18
│                                                  │
│ ▁▁▁▁▁▁▁▁░░░░░░░░░░░░  已用 26%  剩 MOP 1,960      │  y:168 h:4
├──────────────────────────────────────────────────┤  y:180
│ 查看全部 7 张对比                             ▾   │  y:180 h:48
└──────────────────────────────────────────────────┘  y:228
```

**等等 —— 总高需要压到 196px。** 实际是：`16(pad) + 14(label) + 4 + 30(name) + 4 + 18(sub) + 12 + 44(num) + 4 + 18(delta) + 14(bar row) + 0 + 48(trigger) = 226px`。

**修正方案：把额度条与折叠触发器合并到一个 40px 行**（额度条在左、触发器在右）。这样：
`16 + 14 + 4 + 30 + 4 + 18 + 12 + 44 + 4 + 18 + 12 + 40 = 216px`。

**最终取 208px**（额度条行压到 32px，pad 下压到 12px）。若卡名只占 1 行，高度为 **184px**。高度用 `min-height` 而非固定值，允许两行卡名时自然增高——但输入区 `padding-bottom` 必须用**最大的那个态**（208px）计算，宁可有 16px 空隙也不要内容被遮。

### 5.2 逐元素规格

| 元素 | 内容 | 字号/字重/色 | 位置 |
|---|---|---|---|
| 标签 | `刷这张` | 12px / 400 / `--meta` | 上 padding 16px |
| 卡名 | 卡名原文（保留繁体/英文） | 24px / 590 / `--fg`，`tracking-display`，`line-height: 1.25`，**clamp 2 行** | 上距 4px |
| 副行 | `[icon 16] 渠道 · 结算币种` | 13px / 400 / `--fg-2`；图标 `--muted` | 上距 4px |
| **主数字** | `+MOP 23.40` | 40px / 590 / `--pos`，`tabular-nums`，`tracking-display`，`line-height: 1.1`；币种符号 `0.7em`（28px）同色 | 上距 12px |
| 差值行 | `净返 2.34%  ·  比第二名多 MOP 12.80` | 13px / 400 / `--meta`；两个数字均 `tabular-nums` | 上距 4px |
| 额度条行 | 左：4px 进度条（宽 96px）+ `已用 26%`；右：`剩 MOP 1,960` | 条 `--pos`/`--warn`/`--neg`；文字 13px `--meta` | 上距 12px，高 32px |
| 折叠触发器 | `查看全部 7 张对比` + `chevron-down` 16px | 14px / 510 / `--fg-2`，整行 48px 高，`--radius-none`，hover 底 `--surface-2` | 整行可点 |

### 5.3 主数字的三段拆分（实现细节）

```
[+]  [MOP]        [23.40]
28px 20px(0.7em)  40px
--pos --pos       --pos
```

- `+` / `−` / `±` 属于金额，**必须在**,28px
- 币种符号 `0.7em`（28px）—— `HK$` 是上下文，`23.40` 是答案
- **不用 monospace**，全 `tabular-nums`
- 三者用同一个 `--pos` 色（不把符号调暗——符号是语义载体，不是装饰）

### 5.4 五态高度与内容

| 态 | 高度 | 内容 |
|---|---|---|
| **empty（首次/金额空）** | 208px（`min-height` 撑住） | 12px `--muted` 标题 + 14px `--fg-2` 正文。**40px 位留空但高度锁定**。无折叠触发器 |
| **loading（>300ms）** | 208px | 40px 位显示 `——`（两个破折号，tabular 宽度稳定）。**不转 spinner、不骨架屏** |
| **有结果** | 184–208px | 见 §5.1 |
| **失格（全部卡不可用）** | 160px | `这几张卡本月额度都用完了`（16px/510）+ 次优解行 `改用 X 卡可以拿 +MOP 8.20`（13px `--fg-2`）+ 主按钮 `查看额度`（44px） |
| **error** | 160px | `读不到卡片数据`（16px/510）+ 说明（13px `--fg-2`）+ `重试` + `去导入备份`（ghost） |

**空态文案（直接取用，非占位）**

- 首次打开：标题 `选个类别和金额，立刻知道刷哪张`；正文 `地区默认澳门，渠道默认上次用的那个。只要输入金额就会出答案。`
- 金额未填：标题 `还差一个金额`；正文 `输入这笔消费多少钱，答案就会出现在这里。`

> **为什么不用骨架屏**：骨架屏承诺「马上就好」，但这里不是加载慢，是用户还没输入。骨架屏会让用户等一个不会来的东西。

### 5.5 场景 1 / 5 在答案卡上的具体呈现

**场景 1（渣打 Simply Cash，名义 2% 实际 0.05%）**：答案卡显示 `+MOP 0.50` / `净返 0.05% · 名义 2.00%，外币费 1.95%`。**差值行换成「名义 vs 实际」的解释句**，比「比第二名多 X」更有价值——因为这一行的目的是拆掉用户的错觉，不是比排名。

**场景 5（置信度）**：若冠军卡置信度是 `low`/`unknown`，答案卡**折叠触发器上方加一行**（13px `--warn` + `triangle-alert` 14px）：`这张卡此项数据待核对，结论可能偏差`（SPEC AC-F4-03）。这一行必须有，且**在折叠线之上**——放进展开区等于没有。

## 6. 对比 sheet（从折叠触发器展开）

## 7. 交互回路（时序）

| 用户动作 | 系统响应 | 时长 |
|---|---|---|
| 点类别 | 段按钮换色 | 120ms `--motion-fast` |
| 点类别 | 答案卡交叉淡入（旧值 80ms 出 / 新值 120ms 入） | 200ms `--motion-answer` |
| 输入金额（每键） | 200ms debounce → 同上 | 200ms |
| 展开对比 | sheet 从底滑入（`translateY(100%) → 0`） | 220ms `--motion-expand` |
| 展开明细行 | `grid-template-rows: 0fr → 1fr` | 220ms |
| 额度条首绘 | `scaleX(0) → 目标` | 400ms `--motion-progress`（**上限**） |

**明令禁止**：数字滚动计数、页面入场编排、bounce/elastic、闪烁脉冲、同时动画 >3 元素、动画 `width`/`height`。

**reduced-motion**：全部 0.01ms，布局瞬变。

## 8. 响应式

| 断点 | 变化 |
|---|---|
| <375px | gutter 降到 12px；类别格文字降到 12px；金额 28px → 24px |
| 375–639px | 本文基准 |
| 640–1023px | 内容 `max-width: 640px; margin: 0 auto`；答案卡同样居中且宽度 640 |
| ≥1024px | 同 640px 单列居中。**TabBar 保留在底部居中**，不做侧边栏（1 个用户 8 张卡，侧栏是负担） |

**桌面鼠标适配**：pill / 段按钮加 `@media (hover: hover)` 的 hover 态；对比行 hover 底 `--row-hover`。触屏不加 hover（避免「点击残留」）。
